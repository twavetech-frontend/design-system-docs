# Action Button

가장 일반적으로 사용되는 버튼 컴포넌트입니다.
사용자의 주요 액션을 유도하거나, 폼 제출, 다이얼로그 확인 등에 사용합니다.

Figma 컴포넌트: `Buttons/Button`

---

## Hierarchy

버튼의 중요도에 따라 5가지 Hierarchy를 제공합니다.

<ComponentPreview code={`<Button variant="primary">Primary</Button>
<Button variant="secondary">Secondary</Button>
<Button variant="tertiary">Tertiary</Button>
<Button variant="outline">Outline</Button>
<Button variant="ghost">Ghost</Button>`}>
  <Button variant="primary">Primary</Button>
  <Button variant="secondary">Secondary</Button>
  <Button variant="tertiary">Tertiary</Button>
  <Button variant="outline">Outline</Button>
  <Button variant="ghost">Ghost</Button>
</ComponentPreview>

| Hierarchy | 용도 |
| --- | --- |
| **Primary** | 화면에서 가장 중요한 액션. 솔리드 브랜드 컬러(`#7700ff`). 한 화면에 1개 권장 |
| **Secondary** | Primary를 보조하는 액션. 연보라 배경(`#e6d4ff`) + 브랜드 텍스트(`text-brand-primary` `#7700ff`) |
| **Tertiary** | 낮은 우선순위 액션. 옅은 알파 배경(`alpha-black-4`) + 회색 텍스트, hover 시 `alpha-black-12` |
| **Outline** | 흰색 배경 + `border-secondary` 테두리. 표·카드 내부 액션에 적합 |
| **Ghost** | 기본 배경 없음, hover 시 `bg-secondary_hover`. 툴바·메뉴 내부 액션에 적합 |

## Size

5가지 사이즈를 지원합니다. sm/md는 `body-xs`(12px/18px) 텍스트에 `radius-sm`(8px),
lg/xl은 `body-md`(16px/24px), 2xl은 `body-xl`(20px/28px) 텍스트에 `radius-md`(12px)를 사용합니다.

| Size | Height | Font | Radius | Padding |
| --- | --- | --- | --- | --- |
| **sm** | 24px | 12px/18px | 8px | 3px 6px |
| **md** | 32px | 12px/18px | 8px | 6px 14px |
| **lg** | 40px | 16px/24px | 12px | 8px 16px |
| **xl** | 56px | 16px/24px | 12px | 16px |
| **2xl** | 64px | 20px/28px | 12px | 18px 16px |

> Primary는 솔리드 배경 특성상 가로 패딩이 약간 작습니다 (md 12px, lg 12px).
> Disabled 상태는 전체 투명도 20%(`disabled_opacity`)로 처리됩니다.

<Button variant="primary" size="md">MD</Button>
<Button variant="primary" size="lg">LG</Button>
<Button variant="primary" size="xl">XL</Button>
<Button variant="primary" size="2xl">2XL</Button>`}>
