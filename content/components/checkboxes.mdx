# Checkboxes

Checkbox는 사용자가 하나 이상의 항목을 선택하거나 옵션을 켜고 끌 수 있는 컨트롤입니다.
Radio는 여러 옵션 중 하나만 선택할 수 있는 컨트롤입니다.

Figma 컴포넌트: `Base components/Checkboxes`

---

## Type: Checkbox

체크 전에는 1px `border-primary`(`#dce0e5`) 보더만 있고, 체크되면 `bg-brand-solid`(`#7700ff`) 배경에 흰색 체크 아이콘이 표시됩니다.

| State | 스타일 |
| --- | --- |
| **Hover** | 색 변화 없음 (커서만 변경) |
| **Focused** | `focus-ring` (2px 흰색 + 4px 브랜드) |
| **Disabled** | 배경 `bg-disabled_subtle`(`#f3f5f7`), 보더 `border-disabled`(`#dce0e5`), 아이콘 `fg-disabled_subtle`(`#b3bdc7`) |

## Size

sm (16px), md (20px) 두 가지 사이즈를 지원합니다. Checkbox 모서리는 사이즈에 따라 달라집니다 — sm `radius-xs`(4px), md `radius-sm`(8px). 라벨 타이포도 사이즈를 따라갑니다 — sm `body-xs`(12px/18px), md `body-sm`(14px/20px).
