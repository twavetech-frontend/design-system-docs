# Table

테이블은 정렬·필터링·선택 가능한 행 형태로 데이터를 표시하는 컴포넌트입니다. 사용자, 회사, 파일, 거래 내역 등 구조화된 데이터를 한눈에 보여줄 때 사용합니다.

Figma 컴포넌트: `Table`, `Table header cell`, `Table cell`

---

## Team members

Figma의 대표 예시입니다. 카드 헤더(제목 · 카운트 뱃지 · 메뉴), 행 선택, 멀티 뱃지 컬럼, 행 액션 아이콘, 페이지네이션 푸터를 모두 포함합니다.

<ComponentPreview code={`<Table
  title="Team members"
  count="100 users"
  selectable
  pagination
  columns={memberColumns}
  data={teamMembers}
/>

// memberColumns 예시
const memberColumns = [
  { key: 'user', header: '이름', sort: 'desc', render: (r) => <UserCell src={r.avatar} name={r.name} email={r.handle} /> },
  { key: 'status', header: '상태', render: () => <StatusBadge variant="success">활성</StatusBadge> },
  { key: 'role', header: '역할', help: true, muted: true },
  { key: 'email', header: '이메일', muted: true },
  { key: 'teams', header: '팀', render: (r) => <Badges items={r.teams} max={3} /> },
  { key: 'actions', header: '', align: 'right', render: () => <RowActions /> },
]`}>
  <MembersTableDemo />
</ComponentPreview>

## Selectable rows

`selectable` 속성으로 행 선택 체크박스를 추가할 수 있습니다. 헤더 체크박스는 전체 선택 / 전체 해제로 동작합니다.

## Custom cell render

각 컬럼에 `render` 함수를 두면 셀을 자유롭게 커스터마이즈할 수 있습니다. `UserCell`, `StatusBadge`는 헬퍼 컴포넌트로 함께 export 됩니다.

<ComponentPreview code={`const columns = [
  { key: 'name', header: '파일명' },
  { key: 'size', header: '크기', align: 'right' },
  { key: 'status', header: '상태', render: (row) => <StatusBadge variant={row.statusVariant}>{row.status}</StatusBadge> },
  { key: 'uploaded', header: '업로드일', align: 'right' },
]`}>
  <CustomCellTableDemo />
</ComponentPreview>

## Sortable header

컬럼에 `sort` 속성으로 정렬 화살표를 표시할 수 있습니다 (`'asc'`, `'desc'`, `'none'`).
