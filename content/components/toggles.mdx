# Toggles

Toggle(스위치)는 On/Off 두 가지 상태를 가지는 컨트롤입니다.
설정 화면에서 기능을 켜거나 끄는 데 사용합니다.

Figma 컴포넌트: `Toggle`

---

## Type: Default

기본 토글 스위치입니다. 트랙 안쪽에 2px 패딩이 있고 흰색 썸에 `shadow-sm` 그림자가 적용됩니다.

| State | 스타일 |
| --- | --- |
| **Off** | 트랙 `bg-tertiary` (`#e6e8ea`) |
| **On** | 트랙 `bg-brand-solid` (`#7700ff`) |
| **Hover (On)** | 트랙 `bg-brand-solid_hover` (`#6a00e0`) — Off는 변화 없음 |
| **Focus** | `focus-ring` (2px 흰색 + 4px 브랜드) |
| **Disabled** | 트랙 `bg-disabled` (`#f3f4f6`), 썸 `toggle-button-fg_disabled` (`#fafafa`) |

## Size

sm, md 두 가지 사이즈를 지원합니다.

| Type · Size | Track | Thumb |
| --- | --- | --- |
| **Default sm** | 36×20px | 16px |
| **Default md** | 44×24px | 20px |
| **Slim sm** | 32×16px | 16px (풀하이트) |
| **Slim md** | 40×20px | 20px (풀하이트) |
