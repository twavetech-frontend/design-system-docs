# Typography

아임인의 타이포그래피는 두 가지 서체로 구성됩니다.

- **UI — Pretendard** : 제품 UI 전반의 본문·제목에 사용합니다. Regular·Medium·Semibold·Bold 4가지 굵기를 지원합니다.
- **Graphic — Carmen Sans** : 브랜드 그래픽·키비주얼에 사용하는 디스플레이 서체입니다. Regular·Bold·Extrabold 굵기를 지원합니다.

두 서체는 동일한 8단계 타입 스케일을 공유합니다 —
**Heading** xl(48px) · lg(40px) · sm(32px) · xs(24px), **Body** xl(20px) · md(16px) · sm(14px) · xs(12px).
Font Size · Line Height · Font Weight 변수를 묶은 텍스트 스타일 토큰이
CSS 변수로 자동 빌드됩니다.
