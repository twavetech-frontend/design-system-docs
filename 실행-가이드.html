문서 사이트 설치 & 실행 가이드

처음 받는 분도 따라 할 수 있도록 단계별로 정리했습니다.

?먼저 알아두기

이 문서 사이트를 내 컴퓨터에서 보려면 딱 두 가지 프로그램만 설치하면 됩니다. 아래 순서대로 한 번만 설치해 두면, 다음부터는 마지막 “실행” 단계만 반복하면 됩니다.

  • Node.js — 사이트를 실행해 주는 프로그램
  • Git — 소스 코드를 내려받는 프로그램
💡 명령어 입력 창을 사용합니다. Mac은 터미널(Terminal), Windows는 명령 프롬프트(cmd)입니다. 아래 검은색 칸의 명령어를 복사 버튼으로 복사해 붙여넣고 Enter를 누르세요.

1Node.js 설치

1 설치 파일 내려받기

nodejs.org/ko 에 접속해 왼쪽의 “LTS” 버전 버튼을 눌러 설치 파일(.pkg)을 내려받습니다.

내려받은 파일을 더블클릭하고 “계속”만 눌러 설치를 끝냅니다.

2 터미널 열기

Launchpad → “터미널” 검색 또는 Command(⌘) + Space 를 누르고 “터미널” 을 입력해 엽니다.

아래 명령어를 붙여넣고 Enter. 버전 번호(예: v20.x.x)가 나오면 설치 성공입니다.

$ node -v

2Git 설치

1 설치 확인 & 자동 설치

Mac에는 Git이 들어있는 경우가 많습니다. 먼저 터미널에 아래를 입력하세요.

$ git --version

버전 번호가 나오면 이미 설치된 것이니 3단계로 넘어가세요. 만약 설치 안내 창이 뜨면 “설치” 버튼을 눌러 설치를 끝냅니다.

3소스 코드 내려받기

1 원하는 폴더로 이동 후 내려받기

예를 들어 바탕화면(Desktop) 에 받으려면 아래 두 줄을 차례로 입력합니다.

$ cd ~/Desktop $ git clone https://github.com/twavetech-frontend/design-system-docs.git

그 다음 내려받은 폴더 안으로 들어갑니다.

$ cd design-system-docs

4실행하기

1 필요한 부품 설치 (최초 1회)

아래 명령어를 입력합니다. 인터넷 속도에 따라 1~3분 걸립니다.

$ npm install
2 사이트 켜기
$ npm run dev

잠시 뒤 “Ready” 또는 주소가 나타나면, 웹 브라우저(Chrome 등)를 열고 주소창에 아래를 입력합니다.

http://localhost:3000

✅ 화면이 보이면 완료입니다!
⚠️ 사이트를 보는 동안 터미널 창은 닫지 마세요. 그만 보려면 터미널에서 Control + C 를 누르면 종료됩니다.

다음에 다시 볼 때는 터미널에서 폴더로 이동(cd ~/Desktop/design-system-docs)한 뒤 npm run dev 만 입력하면 됩니다.

1Node.js 설치

1 설치 파일 내려받기

nodejs.org/ko 에 접속해 “LTS” 버전 버튼을 눌러 설치 파일(.msi)을 내려받습니다.

내려받은 파일을 더블클릭하고, 체크박스·옵션은 그대로 둔 채 “Next” 와 “Install” 만 눌러 설치를 끝냅니다.

2 명령 프롬프트 열기

키보드 ⊞ (윈도우 키) 를 누르고 “cmd” 를 입력한 뒤 명령 프롬프트 를 엽니다.

아래 명령어를 붙여넣고(마우스 오른쪽 클릭으로 붙여넣기) Enter. 버전 번호(예: v20.x.x)가 나오면 성공입니다.

> node -v

2Git 설치

1 설치 파일 내려받기

git-scm.com/download/win 에 접속하면 설치 파일이 자동으로 내려받아집니다. (안 되면 “Click here to download” 클릭)

내려받은 파일을 더블클릭하고, 모든 옵션을 그대로 둔 채 “Next” 를 계속 눌러 설치를 끝냅니다.

⚠️ 설치가 끝나면 열려 있던 명령 프롬프트 창을 닫고 새로 열어야 Git이 인식됩니다.

3소스 코드 내려받기

1 원하는 폴더로 이동 후 내려받기

예를 들어 바탕화면(Desktop) 에 받으려면 아래 두 줄을 차례로 입력합니다.

> cd %USERPROFILE%\Desktop > git clone https://github.com/twavetech-frontend/design-system-docs.git

그 다음 내려받은 폴더 안으로 들어갑니다.

> cd design-system-docs

4실행하기

1 필요한 부품 설치 (최초 1회)

아래 명령어를 입력합니다. 인터넷 속도에 따라 1~3분 걸립니다.

> npm install
2 사이트 켜기
> npm run dev

잠시 뒤 “Ready” 또는 주소가 나타나면, 웹 브라우저(Chrome 등)를 열고 주소창에 아래를 입력합니다.

http://localhost:3000

✅ 화면이 보이면 완료입니다!
⚠️ 사이트를 보는 동안 명령 프롬프트 창은 닫지 마세요. 그만 보려면 명령 프롬프트에서 Ctrl + C 를 누르면 종료됩니다.

다음에 다시 볼 때는 명령 프롬프트에서 폴더로 이동(cd %USERPROFILE%\Desktop\design-system-docs)한 뒤 npm run dev 만 입력하면 됩니다.

!잘 안 될 때

  • ‘git’ / ‘node’ / ‘npm’ 을(를) 찾을 수 없습니다 → 해당 프로그램이 설치 안 됐거나, 설치 후 명령어 창을 새로 열지 않은 경우입니다. 창을 닫고 다시 열어 보세요.
  • npm install 중 멈춘 것 같을 때 → 실제로는 진행 중인 경우가 많습니다. 2~3분 기다려 주세요. (인터넷 연결 필요)
  • localhost:3000 이 안 열릴 때 → npm run dev 명령어 창에 “Ready” 가 떴는지 확인하고, 주소를 정확히 입력했는지 보세요.
